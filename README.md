# Tank Battle V2 · Sunset Front

一个纯 HTML + Canvas + JavaScript 编写的单文件战役版坦克大战。无需安装依赖，直接双击 `index.html` 即可运行。

## V2 内容

- **夕阳战术沙盘**：沙漠公路、军事哨站、混凝土掩体、沙尘、烟雾、火光和暖色夕阳 HUD。
- **五章战役**：检查站突破、补给线护航、前沿基地防守、炮兵阵地摧毁、夕阳山谷 Boss 战。
- **多种任务目标**：清场、护送、限时防守、摧毁目标和 Boss 击破。
- **战术技能树**：装甲、穿甲火力、机动、弹药、侦察网络、无人机支援。
- **敌人类型**：侦察车、突击坦克、重装坦克、火炮车、指挥坦克和峡谷指挥官。
- **战场表现**：可破坏砖墙/钢墙、道路、水域、灌木、补给箱、粒子爆炸、履带式坦克和战术小地图。
- **本地存档**：最高分、完成章节、技能配置和屏幕震动偏好保存在浏览器 `localStorage`。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |
| `V` | 屏幕震动开关 |
| `1` - `6` | 在战术整备界面购买技能 |
| `R` | 重新开始战役 |
| `Enter` | 开始、继续或返回标题 |

## 运行

直接使用浏览器打开 `index.html`，也可以使用任意静态服务器运行。项目不依赖网络、构建工具或第三方库。

## 技术实现

- 单文件、零依赖 Canvas 2D 游戏。
- `requestAnimationFrame` 游戏循环与固定上限的时间步长。
- 网格地图、AABB 碰撞、敌人巡逻/追击/射击逻辑。
- Canvas 程序化绘制夕阳、地形、坦克、HUD、小地图和粒子效果。
- Web Audio API 生成基础射击、升级和爆炸音效。
