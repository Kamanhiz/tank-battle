# 坦克大战 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 编写的经典《坦克大战》(Battle City) 网页游戏。无需任何依赖，双击打开 `index.html` 即可游玩。

## 运行方式

直接使用浏览器打开 `index.html`，或在任意静态服务器下运行：

```bash
# 例如用 Python（可选）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `R` | 重新开始 |
| `Enter` | 开始 / 返回标题 |

## 游戏内容

- **保护基地**：守住地图底部的鹰旗，被子弹或敌人摧毁即游戏结束。
- **消灭敌人**：每关 15 辆敌方坦克，全部击毁进入下一关（共 3 关）。
- **四种敌人**：普通（银色）、快速（蓝色）、强力（绿色）、装甲（红色，需 3 次命中）。
- **可破坏地形**：砖墙（可击碎）、钢墙（需满级火力）、水域（坦克不能通行）、树林（可藏身）。
- **道具**：击毁闪烁的敌方坦克会掉落道具——
  - ★ 火力升级（提升射速、双发、可击穿钢墙）
  - 💥 炸弹（消灭场上所有敌人）
  - ◆ 护盾（临时无敌）
  - + 生命
  - ❄ 冰冻（冻结敌人）
- **分数与最高分**：最高分保存在浏览器本地（localStorage）。

## 技术实现

- 单文件、零依赖，约 800 行代码。
- Canvas 2D 渲染，`requestAnimationFrame` 游戏循环，按时间步长 (`dt`) 计算移动。
- 网格化地图 + AABB 碰撞检测，坦克转向自动对齐网格。
- Web Audio API 生成射击 / 爆炸 / 道具音效（无外部音频文件）。
